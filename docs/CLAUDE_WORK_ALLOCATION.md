# 클로드와 작업 분담

2026-10-25: 사용자의 요청에 따라 안내 웹페이지의 소개 문구 검토를 Claude Code Sonnet, low effort, 도구 없이 단일 호출로 수행했다. 응답은 짧은 소개 문구이며 사실·링크·브라우저 검증과 최종 구현은 Codex가 맡았다.

운영 원칙: 같은 파일을 두 모델이 동시에 수정하지 않는다. 먼저 로컬 검사와 실제 오류를 확인하고 필요한 범위만 전달한다. 전체 대화·큰 이미지·로그를 매번 다시 전달하지 않는다. 자동 재시도와 무한 반복 호출을 하지 않는다. 시각 자산은 별도의 이미지 도구로 제작한다. Claude 호출 한 번마다 결과와 필요한 다음 작업을 판단한다.

이 분담은 중복 사용을 줄이는 방법이다. 계정의 남은 할당량을 자동으로 조회하거나 두 회사의 사용량을 서로 이전하는 시스템은 아니다. 구독형 사용 한도·초기화 시점·다른 대화의 사용량까지 통제하거나 제한 회피를 보장하지 않는다. 제한 응답이 오면 반복 호출을 멈추고 가능한 검증·구현을 진행한다.

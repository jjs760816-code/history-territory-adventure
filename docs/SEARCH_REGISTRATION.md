DNS 인증은 chatgpt.site 도메인을 소유하지 않으므로 URL 접두어 속성+HTML 인증을 사용한다. 등록 요청이 검색 노출이나 순위를 보장하지 않는다. 나무위키 및 블로그에 게시 완료했다고 주장하지 않는다.

제목·본문의 역사 놀이/역사 게임/초등 한국사 설명, canonical, robots, JSON-LD WebSite/CollectionPage/ItemList, 사이트맵 적용. 복제 GitHub Pages 포털도 대표 canonical은 공용 Sites 주소다. GitHub 프로젝트 하위의 robots.txt는 github.io 호스트 루트 robots.txt를 대신하지 않는다.

Google Search Console과 네이버 서치어드바이저 소유권 확인·사이트맵 제출 여부는 별도 확인해야 한다. 사용자 계정 로그인 후 제공되는 HTML 메타 태그를 루트 index.html과 game-room.html head에 추가하거나 HTML 인증 파일을 public에 추가하고 기존 사이트를 재배포한다. 메타 인증 값은 공개 값이지만 비밀번호·OAuth 토큰은 소스에 넣지 않는다. DNS 인증은 chatgpt.site 도메인을 소유하지 않으므로 URL 접두어 속성+HTML 인증을 사용한다. 등록 요청이 검색 노출이나 순위를 보장하지 않는다. 나무위키 및 블로그에 게시 완료했다고 주장하지 않는다.

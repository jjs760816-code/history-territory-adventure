## 핵심 순환

지역 선택 → `POST /api/regions/:id/challenge` (서버가 문제 선택·보기 셔플·1회용 ID 발급, 플레이어당 진행 중 도전 1개)
→ `POST /api/answer {challengeId, choiceIndex}` (트랜잭션 안에서 도전 삭제 → 판정 → 보상 → 점령 → 카드)
→ 상태 갱신 → 조건 충족 시 `POST /api/advance`.

## 초기 수치와 계산 규칙

| 항목 | 값 |
| --- | --- |
| 시작 | 구석기, 경험치 0, 식량 20, 인구 10 |
| 처음 정답 | 경험치 10 + 5×(난이도−1), 식량 +4, 인구 +2 (문제당 1회, `rewards`의 `q:<id>`) |
| 반복 정답 | 보상 없음, 기록만 |
| 오답 | 손실 없음, 복습 목록에 추가 |
| 중립 지역 점령 | 그 지역 시대 문제 정답 1회 → 식량 +6, 인구 +3 (지역당 1회, `capture:<id>`) |
| 경쟁 부족(시연용) 지역 | 정답 2회 누적 시 점령. 오답은 진행 없음 |
| 국력 | 인구 + ⌊식량/2⌋ + 영토×8 + 카드 국력 보너스 |
| 도전 유효 시간 | 30분, 1회용 |

경험치만 쌓아서는 발전할 수 없다(고유 문제 수·미션·국력 동시 충족). 같은 문제 반복은 경험치를 주지 않는다. 삼국 이후 시대는 지도 구역 점령이 아니라 미션 문제(`POST /api/missions/:id/challenge`)로 배운다. 발전 시 `era = 현재 시대` 조건부 UPDATE와 `era_log` 기록을 같은 트랜잭션에서 하고, 그 안에서 새 시대 미션·카드를 정산한다.

### 미션과 보상

- 상태: `locked`(뒤 시대) / `active` / `completed`(조건 충족, 정산 전) / `rewarded`. 정산(`settleMissions`)은 답변·발전 트랜잭션 안에서 하고 `rewards`의 `m:<id>` 기본키로 한 번만 지급한다. 미션 카드도 `INSERT OR IGNORE`.
- 이전 저장본은 열 때마다 정산을 다시 돌리지만 기본키 때문에 결과가 같다(멱등).
- 화면 알림: 알린 미션 id를 `hta_seen_missions_v1:<ref>`(localStorage, `ref`는 플레이어 id 해시 12자, 비밀 아님)에 기억한다. 필수 핵심 미션은 바로, 그 밖의 핵심 미션은 그 시대 정답 2개 이후, 사건·기회 미션은 정답 2개마다 1개씩(한 번에 최대 2개) 알린다(`recommendations.js`). 알림 순서만 정하며 보상 판정과 무관하다.
- 시작 대화상자: 새 원정대는 배경 이야기 5장면 → 게임 안내 → (닫힌 뒤) 첫 미션 알림. 돌아온 플레이어는 이야기를 강제로 보지 않고, 그동안 새로 열린 미션만 알린다. 알림은 다른 대화상자·시대 연출이 열려 있으면 기다린다.

### 카드(15)

주먹도끼, 불 다루기, 전곡리 유적(구석기) / 빗살무늬 토기, 가락바퀴, 암사동 움집 마을(신석기) / 비파형 동검, 고인돌, 단군 건국 이야기[신화·설화](청동기·고조선) / 미션 보상 카드: 가야의 덩이쇠, 불국사와 석굴암, 팔만대장경, 훈민정음, 대한민국 임시 정부, 제헌 헌법(삼국 이후 시대마다 1장, 코드로 그린 상징 도형).
효과는 식량 보너스(처음 정답 시), 점령 시 인구 보너스, 국력 보너스뿐이며 정답 없이 보상을 사는 기능은 없다.

## 지도

`lib/content.mjs`의 `REGIONS`는 지역 ID·지형·문제 시대·초기 소유(중립/시연용 경쟁)·SVG 다각형을 가진다. 게임 소유권은 DB `player_regions`(플레이어별)에 따로 저장한다. 시대별 실제 지명·역사 범위 데이터는 아직 없다(지역 이름은 게임용 지형 이름).

## 보안·무결성 설계

- 정답은 `lib/questions.mjs`에만 있고, 출제 응답에는 섞인 보기만 보낸다. 해설·정답은 답한 뒤에만 반환.
- 도전 ID는 플레이어에 묶여 있고 답하면 즉시 삭제 → 재전송·동시 전송·다른 세션 사용 시 409.
- 보상·카드는 DB 기본키(`INSERT OR IGNORE`)로 중복 차단, 점령은 `owner != 'player'` 조건부 UPDATE로 소유권 재확인.
- 시대 발전은 `era = 현재 시대` 조건부 UPDATE로 동시 요청 시 한 번만 성공.
- 클라이언트가 보낸 경험치·시대·소유권 값은 어떤 API도 읽지 않는다.
- 입력: JSON 객체만, 16KB 제한, 닉네임 2~12자(한글/영문/숫자, 욕설·전화번호 거부), 제출 문제 길이·형식 검사.

## 테스트 범위

콘텐츠 무결성(개수·필드·정답 위치 분포), 정적 경로 노출 차단, 출제 응답 정답 미노출, 보기 셔플, 오답 처리와 복습, 동시 재전송·반복 정답 중복 보상 방지, 시대 잠금·발전 조건·동시 발전, 경쟁 지역 2회 점령, 세션 격리·위조 쿠키, 클라이언트 값 무시, 비정상 입력(닉네임·JSON·크기·Content-Type·보기 번호·Origin), 제출 문제 형식 검사·검토 대기·출제 미노출, 학습 기록 정답 숨김, 서버 재시작 후 상태·기록·제출·진행 중 도전 복원.

## 화면·지도·소리 (프론트엔드)

- `public/app.js`는 부팅 때 `/api/meta`와 `/assets/cartography.json`을 함께 읽는다. 지도 자료를 못 읽으면 구역만 그린다.
- 점령 지도: 현재 해안선(`landPath`) ∩ 게임 영역(`gameAreaPath`) 이중 clipPath 안에 16개 구역을 칠한다. 지명은 화면 배율에 맞춘 크기로 우선순위(선택 > 소유·경쟁 > 중립 > 잠김)대로 겹치지 않는 자리에만 놓는다. 자리가 없는 지명은 숨기되 구역 색·★/⚑ 표식·“지역 고르기” 목록·접근성 이름으로 확인할 수 있고, 확대하면 더 많이 보인다.
- 역사 지도: 구석기/신석기/고조선 미리보기 탭(플레이어 진행과 무관). 구석기·신석기는 유적 점만 표시하고 국경을 그리지 않는다. 고조선은 문화 범위 점선과 “문화 범위 참고 · 확정 국경 아님” 표기. 유적 정보는 별도 영역에 표시하며 게임 지역 패널을 덮어쓰지 않는다.
- 울릉도·독도는 실제 크기를 키우지 않고 선택 가능한 점 표식으로 둔다. 현대 국가 경계선은 그리지 않는다.
- 카드 그림은 `artifact-atlas.webp`(3×3) 위치로 표시하며, 비파형 동검은 아틀라스 대신 코드로 그린 SVG 도식을 쓴다. 미획득 카드는 흑백 실루엣.
- `public/audio.js`: 배경음은 이 게임용으로 합성한 `assets/river-dawn.wav`(`scripts/build-soundtrack.py`), 불러오지 못하면 WebAudio 5음 음계로 대체. 효과음(선택·정답·오답·점령·시대·카드)은 WebAudio. 배경음·효과음 각각 기본 꺼짐, 켬 설정은 사용자 동작 이후에만 되살리며, 탭이 숨겨지면 멈춘다. 효과음은 서버가 확정한 응답에만 붙는다.
- `prefers-reduced-motion`이면 점령 반짝임·시대 연출·카드 뒤집기 애니메이션을 끈다.
- 배경 이야기의 박정재 교수 기후·이동 설명은 "연구 가설"로 표시하며 채점 문제로 내지 않는다(`campaign.test.mjs`가 검사). 탐구 노트의 꽃가루 사례도 가설을 정답으로 고르게 하지 않고 "신중한 추론"을 고르게 한다.

- 이 점검에서 하지 않은 것: 실제 브라우저(데스크톱·모바일) 화면 점검과 온라인 배포(담당 검토자 수행). push하지 않았다.

### 남은 한계(구체)

- 1인용: 다중 사용자·방·교사 관리 없음. 웹 체험판은 브라우저마다 따로 저장되고, 문제은행이 함께 내려가므로 정답을 볼 수 있다.
- 문제 94개 모두 검수 대기(출처 원문 대조 전). 제출 문제 승인 기능 없음.
- 삼국 이후 6개 시대는 지도 구역을 점령하지 않고 미션 문제로만 진행한다. 역사 지도 미리보기와 문화 범위는 처음 3개 시대만.
- 미션 추천 가중치는 단일 회차(71회 기본) 독자 분류 표본이며, 선사 시대 핵심 미션 배치는 표본이 아니라 잠정 설계다.
- 새 카드 6장은 삽화 없이 코드 도형. 안내인 복식은 상상 삽화.
- 추리·탐구 노트는 준비된 피드백뿐(AI·서술형 채점 없음), 보상 없음.

# 구현 메모 (v0.1 로컬 1인 시연판)

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `server.mjs` | HTTP 서버, 라우팅, 정적 파일(`public/`만), 보안 헤더, 쿠키 세션, `/api/meta` |
| `lib/game.mjs` | 판정·보상·점령·카드·미션·시대 발전·제출 형식 검사 (서버 권위) |
| `lib/questions.mjs` | 문제은행(정답 포함, 서버 전용 — 정적 경로 밖) |
| `lib/content.mjs` | 시대·지역 도형·카드·미션·수치 (정답 없음, 공개 가능) |
| `lib/db.mjs` | `node:sqlite` 스키마와 트랜잭션 |
| `public/` | `index.html`, `app.js`, `style.css` (판정 로직 없음) |
| `test/game.test.mjs` | 구현 측 테스트 |
| `test/reviewer.test.mjs` | 검토자 회귀 테스트(외부 작성, 보존) |
| `test/helpers.mjs` | 테스트 도우미(테스트에서만 정답 조회) |

## 핵심 순환

지역 선택 → `POST /api/regions/:id/challenge` (서버가 문제 선택·보기 셔플·1회용 ID 발급, 플레이어당 진행 중 도전 1개)
→ `POST /api/answer {challengeId, choiceIndex}` (트랜잭션 안에서 도전 삭제 → 판정 → 보상 → 점령 → 카드)
→ 상태 갱신 → 조건 충족 시 `POST /api/advance`.

## 초기 수치와 계산 규칙

| 항목 | 값 |
| --- | --- |
| 시작 | 구석기, 경험치 0, 식량 20, 인구 10 |
| 처음 정답 | 경험치 10 + 5×(난이도−1), 식량 +4, 인구 +2 (문제당 1회, `rewards`의 `q:<id>`) |
| 반복 정답 | 보상 없음, 기록만 |
| 오답 | 손실 없음, 복습 목록에 추가 |
| 중립 지역 점령 | 그 지역 시대 문제 정답 1회 → 식량 +6, 인구 +3 (지역당 1회, `capture:<id>`) |
| 경쟁 부족(시연용) 지역 | 정답 2회 누적 시 점령. 오답은 진행 없음 |
| 국력 | 인구 + ⌊식량/2⌋ + 영토×8 + 카드 국력 보너스 |
| 도전 유효 시간 | 30분, 1회용 |

### 시대 발전 조건

| 이동 | 경험치 | 서로 다른 문제 처음 정답 | 국력 | 필수 미션 |
| --- | --- | --- | --- | --- |
| 구석기 → 신석기 | 60 | 구석기 6 | 50 | 첫 터전 마련(영토 3곳) |
| 신석기 → 청동기·고조선 | 150 | 신석기 6 | 100 | 정착과 농경(강가·평야·해안 신석기 지역 2곳) |

경험치만 쌓아서는 발전할 수 없다(고유 문제 수·미션·국력 동시 충족). 같은 문제 반복은 경험치를 주지 않는다.

### 카드(9)

주먹도끼, 불 다루기, 전곡리 유적(구석기) / 빗살무늬 토기, 가락바퀴, 암사동 움집 마을(신석기) / 비파형 동검, 고인돌, 단군 건국 이야기[신화·설화](청동기·고조선).
효과는 식량 보너스(처음 정답 시), 점령 시 인구 보너스, 국력 보너스뿐이며 정답 없이 보상을 사는 기능은 없다.

## 지도

`lib/content.mjs`의 `REGIONS`는 지역 ID·지형·문제 시대·초기 소유(중립/시연용 경쟁)·SVG 다각형을 가진다. 게임 소유권은 DB `player_regions`(플레이어별)에 따로 저장한다. 시대별 실제 지명·역사 범위 데이터는 아직 없다(지역 이름은 게임용 지형 이름).

## 보안·무결성 설계

- 정답은 `lib/questions.mjs`에만 있고, 출제 응답에는 섞인 보기만 보낸다. 해설·정답은 답한 뒤에만 반환.
- 도전 ID는 플레이어에 묶여 있고 답하면 즉시 삭제 → 재전송·동시 전송·다른 세션 사용 시 409.
- 보상·카드는 DB 기본키(`INSERT OR IGNORE`)로 중복 차단, 점령은 `owner != 'player'` 조건부 UPDATE로 소유권 재확인.
- 시대 발전은 `era = 현재 시대` 조건부 UPDATE로 동시 요청 시 한 번만 성공.
- 클라이언트가 보낸 경험치·시대·소유권 값은 어떤 API도 읽지 않는다.
- 입력: JSON 객체만, 16KB 제한, 닉네임 2~12자(한글/영문/숫자, 욕설·전화번호 거부), 제출 문제 길이·형식 검사.

## 테스트 범위

콘텐츠 무결성(개수·필드·정답 위치 분포), 정적 경로 노출 차단, 출제 응답 정답 미노출, 보기 셔플, 오답 처리와 복습, 동시 재전송·반복 정답 중복 보상 방지, 시대 잠금·발전 조건·동시 발전, 경쟁 지역 2회 점령, 세션 격리·위조 쿠키, 클라이언트 값 무시, 비정상 입력(닉네임·JSON·크기·Content-Type·보기 번호·Origin), 제출 문제 형식 검사·검토 대기·출제 미노출, 학습 기록 정답 숨김, 서버 재시작 후 상태·기록·제출·진행 중 도전 복원.

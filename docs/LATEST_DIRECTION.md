# 현재 제품 방향

사용자가 정한 제목: **역사 탐험 1**.

가상 시간여행 캐릭터와 함께 한반도의 선사 생활부터 현대까지 변화 단계를 체험한다. 시작 설명→기후와 인류 이야기→지도 탐험→문제와 해설→사건/기회 미션→보상→다음 시대로 이어진다. 캐릭터 복식은 시대에 따라 바뀌는 학습용 상상 삽화이며, 동일 인물이 실제로 수천 년을 살았다는 뜻이 아니다.

이후에는 단서 관찰, 질문, 근거를 고른 답변, 추론과 재질문의 흐름으로 탐구를 확장한다. 초기 탐구 노트는 미리 준비한 단서와 피드백으로 제공하고, 자유 문답 AI가 연결되지 않았으면 연결되었다고 표시하지 않는다.

학생들이 설치 없이 접속하는 온라인 웹 체험판을 우선 배포한다. 현재 GitHub Pages 체험판은 각 학생 브라우저에 별도 저장된다. 실제 다중 사용자 영토 경쟁과 교사 학급 관리가 구현된 것으로 표현하지 않는다.

# 독립 실행 점검 및 피드백

점검일: 2026-10-22 (한국 시간)

## 현재 결과

Claude Code로 첫 구현과 수정 작업을 수행한 뒤, 별도로 서버와 브라우저를 실행해 점검했다. 최종 기능 테스트는 **22개 통과, 실패 0개**다. 화면 문구와 CSS 작성 방식을 그대로 대조하던 검사 1개는 실제 브라우저 점검으로 대체했다. 이 결과는 로컬 1인 시연판의 검증이며, 온라인 다중 사용자 서비스나 역사 문제 전체의 사실 검수가 완료되었다는 뜻은 아니다.

## 확인한 동작

- 닉네임 시작 → 지역 선택 → 문제 출제 → 정답 제출 → 경험치·자원·점령·카드 획득을 실제 브라우저로 확인했다.
- 실제 문제를 풀이하는 독립 시나리오로 구석기 → 신석기 → 고조선의 두 차례 시대 발전을 확인했다. 조건 미달 시 발전은 거부된다.
- 문제의 정답과 해설은 풀이 전 응답에 포함되지 않는다. 서버 코드·문제은행·저장 파일 및 인코딩된 상위 경로 접근은 404다.
- 다른 세션의 도전 답변, 같은 답변 재전송, 클라이언트의 경험치·시대·영토 값 조작을 차단한다.
- 오답의 무보상, 복습, 이미 푼 문제의 중복 보상 제한, 경쟁 지역 2회 정답 점령을 테스트했다.
- 데이터베이스 재연결 및 서버 재시작 뒤 플레이어·학습·영토·카드·제출 문제 저장 복원을 확인했다.
- 브라우저에서 직접 만든 문제를 제출하여 ‘검토 대기·AI 검토 미연결’로 저장되는 것을 확인했다. 제출 문제는 출제·보상에 반영되지 않는다.
- 390×844 화면에서 페이지와 출제 양식의 가로 넘침이 없음을 확인했다. 지도 확대가 가로·세로를 함께 늘리고 원래 크기로 돌아오는 것을 확인했다.

## 발견하고 수정한 사항

1. JSON null 요청이 서버 오류(500)를 만들었다. JSON 객체만 허용하고 잘못된 값은 400으로 거부하도록 수정했다.
2. `toString` 같은 객체 상속 속성이 시대 값으로 허용됐다. 명시적인 소유 속성 검사를 적용했다.
3. 전화번호 형태의 닉네임을 허용했다. 개인정보 및 긴 숫자 패턴을 거부하도록 수정했다.
4. 잘못 인코딩된 쿠키가 서버 오류를 만들 수 있었다. 해당 쿠키를 무시하고 미인증 상태로 처리한다.
5. CSS가 hidden 속성을 덮어 시작 전 빈 게임 영역과 메뉴가 나타났다. hidden의 표시 우선순위를 보장했다.
6. 지도가 기본 배율에서 잘리고 지역명이 겹쳤다. 지도 전체 맞춤, 가로·세로 확대, 지명 줄바꿈을 적용했다.
7. 구석기 보상에 곡식을 표시해 농경과 혼동할 수 있었다. 게임 자원과 보상·효과 안내는 식량으로 바꾸고, 역사 문제의 곡식 표현은 유지했다.
8. 교육과정 대조 전에 특정 학기(5-2)를 표시했다. ‘초등 사회 역사 영역, 교육과정 연결 검토 예정’으로 바꿨다.
9. 처음 화면으로 돌아갈 때 브라우저 기본 확인 창에서 검증 도구가 멈췄다. 화면 안의 확인 대화상자로 교체하고, 서버 요청 실패 시 다시 시도할 수 있게 했다. 기본 확인 창이 아닌 새 대화상자의 최종 브라우저 확인 여부는 후속 점검 기록을 따른다.

입력 검증 결함과 전체 시대 진행·저장 복원은 `test/reviewer.test.mjs`에 독립 회귀 테스트로 남겼다.

## 다음 개발 우선순위

1. 자체 문제 33개의 근거 원문 대조, 정확한 출처·확인일·교육과정 성취기준 기록. 현재 모두 검수 대기이며 기출 원문은 사용하지 않는다.
2. 실제 지형과 시대별 지명·활동 범위를 구분하는 지도. 현재 지도는 기능 시연용이고 국경을 재현하지 않는다. 기본 배율의 지역명 가독성도 추가 개선할 수 있다.
3. 교사·관리자의 서버 권한과 문제 승인·수정 확인·오류 신고.
4. 학급별 비공개 방과 실제 다중 사용자 점령·동기화, 보호 시간, 경쟁 균형.
5. 여러 나라·삼국 이후 시대, 고조선 상징 경로, 스킬과 추가 사건.

현재 서버는 기본적으로 이 컴퓨터의 127.0.0.1에만 열리며 공개 배포하지 않았다. 학생이 함께 접속하는 정식 온라인 수업용으로 사용하려면 README의 미완료 기능을 구현해야 한다.

# 역사 영토 원정대 — 제품 요구사항

## 목적
초등학교 5학년이 한국사 문제를 풀고 직접 출제하면서 지도의 영토와 문명을 성장시키는 한국어 웹 게임. 삼국지14의 지도 중심 전략 감각을 참고하지만 자산과 디자인은 독자 제작한다.

## 전체 방향
구석기 → 신석기 → 청동기·고조선 → 여러 나라의 성장 → 삼국·가야 → 통일 신라·발해 → 고려 → 조선 → 근현대.
동시에 존재했던 국가는 병렬 관계로 설명하고 단일 계승 관계처럼 오해하게 만들지 않는다.
고조선에는 환웅·곰·호랑이 설화에 착안한 상징 경로, 이후 여러 나라와 삼국·가야·신라·발해의 선택을 제공한다. 고려·조선에는 당시 신분과 직업에 관한 역할 학습, 근현대에는 시대에 맞는 탐구 역할을 제공한다. 신화 기반 선택은 창작 설정으로 표시한다.

## 지도
장기 범위는 한반도·부속 도서·옛 고구려 활동 범위. 지역 ID/지형, 시대별 지명/역사 정보, 게임 소유권을 분리한다. 역사적 국경의 불확실성과 시대별 접근 범위를 표시한다. 첫 버전은 12~20개 클릭 가능한 지역의 시연용 지도. 이동·확대축소 또는 사용하기 편한 반응형 지도. 지역 상세와 문제 풀이·출제 동작 제공.

## 핵심 순환
지역 선택 → 문제 풀이 → 서버 정답 판정 → 경험치·자원·카드 → 지역 점령 → 학습 숙련도와 미션 달성 → 시대 발전.
경험치만 반복해서 얻어 다음 시대에 진입하지 못하게 한다. 정답 경험치, 고유 문제 학습 수, 필수 미션, 국력 등의 분명한 조건과 진행률 표시. 같은 문제 반복 보상은 제한하며 오답 복습은 허용한다.

## 문제은행
구석기·신석기·고조선 자체 제작 문제 약 30개. 객관식부터 구현. 각 문제에 ID, 버전, 시대, 지역 또는 주제, 학습 목표, 난이도, 질문, 보기, 정답, 쉬운 해설, 출처와 검수 상태 저장. 기출 원문·이미지는 이용 조건 확인 전 사용하지 않는다.
신뢰 출처는 국사편찬위원회·국립박물관·국가유산청·공식 교육과정 등. 실제로 자료를 읽지 못한 문제는 검증 완료로 표시하지 않는다. 정답은 서버에만 보관하고 API의 출제 응답에 포함하지 않는다.

## 출제와 승인
사용자는 중립 지역에서 문제, 보기, 정답, 해설, 참고 자료를 제출한다. 자동 형식 검사로 정답/보기 유효성, 개인정보·욕설, 출처 누락 등을 확인한다. 역사적 사실 판단을 형식 검사로 대신하지 않는다.
AI 검증 미연결 상태에서는 검토 대기로 저장한다. 미승인 문제는 출제하거나 점령 보상에 사용하지 않는다. 오탈자 외 정답·의미 변경은 작성자의 확인 필요. 관리자 승인 기능을 만들면 서버 권한을 적용한다. 브라우저의 관리자 버튼만으로 권한을 보호했다고 주장하지 않는다.
승인된 문제의 점령 처리는 현재 소유권을 다시 확인하며 중복 보상을 막는다.

## 영토와 자원
중립 영토는 문제 풀이 또는 승인된 출제로 점령. 다른 플레이어의 영토는 지역 도전 문제 정답 조건을 충족해 점령. 점령 보호 시간, 동일 상대와 반복 보상 제한, 신규 플레이어 보호 필요. 처음 혼자 하는 버전에서 상대를 AI/시연으로 넣으면 명시한다.
영토를 잃어도 개인 학습 기록과 도감은 유지한다. 자원은 인구·곡식·경제력·군사력·기술력·문화력. 첫 버전은 이해하기 쉬운 주요 수치부터 연결하고 계산 규칙을 공개한다. 접속을 오래 하지 않았다고 큰 손실을 주지 않는다.

## 카드·스킬·사건
카드 종류는 인물/장수·유물·유적·기회·사건. 첫 버전 카드 6~10개. 시대, 역사 설명, 게임 효과, 획득 조건을 관리한다. 시대와 맞지 않는 인물 사용과 도감 수집을 구분한다.
농경·교역·문화·기술·외교·방어 스킬로 확장할 수 있다. 효과는 정답 없이 보상을 사는 방식이 아니라 학습과 성장에 연결한다.
정착/농경, 청동기 문화 등 초기 미션을 제공하고 실제 역사와 게임 선택 결과를 구분한다.

## 온라인과 보안
1단계는 혼자서 핵심 루프를 실행·저장하는 버전. 2단계는 소규모 비공개 방, 참가 코드, 닉네임과 실제 다중 사용자 동기화. 개인 시대와 방의 경쟁 시대를 구분한다.
모든 판정은 서버가 한다. 임의 클라이언트 XP/시대/소유권을 신뢰하지 않는다. 동일 답변 재전송·동시 점령·중복 보상 방지. 학생 개인정보 최소 수집. 공개 채팅 없음. API 키는 서버 환경 변수만 사용.
첫 버전이 로컬 데모이면 공용 서버 운영을 위한 인증/접근제어의 미완료 범위를 표시한다.

## 화면
어린이가 사용하기 쉬운 지도 중심 메인, 현재 시대/경험치/자원 요약, 지역 상세, 문제 모달, 정답/오답 해설, 문제 만들기, 도감, 미션, 시대 발전, 학습 기록. 반응형이고 글자와 대비가 충분해야 한다. 버튼은 실제 동작해야 한다.

## 완성 기준
시작 → 지도 → 문제 → 판정 → 보상 → 점령 → 저장 → 시대 발전을 실행 가능하게 만든다.
외부 API 없이 실행 가능. README에 실행법, 설정값, 저장 방식, 구현/미구현 항목 기록. 단위·통합 테스트를 실행하고 결과를 정리한다. 적어도 잘못된 답변, 반복 정답, 답 미노출, 저장 복원, 미승인 문제, 유효하지 않은 입력을 검사한다.

## 이후 확장
여러 나라·삼국·가야·남북국, 고려·조선·근현대, 실제 지도 데이터, 교사 화면, 근거 기반 AI 문제 검토, 협동과 비공개 온라인 방을 단계적으로 확장한다.

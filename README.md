# 역사 탐험 1 (1인 시연판 v0.1 · 로컬 서버판 / 웹 체험판)

초등 5학년용 한국사 학습 지도 게임. 가상 안내인 하람과 함께 배경 이야기(기후와 인류 이동)로 시작해, 문제를 풀어 지역을 점령하고 사건·기회 미션을 해결하며 구석기 → 신석기 → 청동기·고조선 → 삼국·가야 → 남북국 → 고려 → 조선 → 개항기·독립운동 → 대한민국(9개 시대)으로 원정대를 발전시킨다.

> **이 버전은 1인용이다.** 로컬 서버판과 GitHub Pages 웹 체험판 모두 혼자 하는 게임이며, 방 기반 온라인 경쟁, 참가 코드, 실시간 다중 사용자 동기화, 교사 학급 관리는 **구현되지 않았다.** 웹 체험판은 학생마다 자기 브라우저에 따로 저장된다.
> 지도의 "경쟁 부족"은 시연용 컴퓨터 설정이며 실제 온라인 사용자가 아니다.
> 지도 바탕은 현재 해안선을 바탕으로 독자 제작한 그림이고, 색칠한 16개 구역은 **게임 규칙**이며 실제 역사 국경이 아니다.

## 웹 1인 체험판 (GitHub Pages)

바로 해 보기: https://jjs760816-code.github.io/history-territory-adventure/

- 설치 없이 브라우저에서 실행된다. `main`에 올라오면 GitHub Actions(`.github/workflows/pages.yml`)가 `npm test` 통과 후 `node scripts/build-pages.mjs`로 `dist/`를 만들어 배포한다.
- 게임 규칙(`lib/game.mjs`)·콘텐츠·화면(`public/`)은 로컬 서버판과 같은 파일을 쓴다. 차이는 저장소와 판정 위치뿐이다.
  - 저장: `node:sqlite` 대신 sql.js(SQLite WASM, MIT, `pages/vendor/`에 포함)를 쓰고, DB를 **그 브라우저의 localStorage**에 보관한다. 다른 기기·브라우저와 공유되지 않는다.
  - 판정: 브라우저 안에서 한다. 문제은행이 함께 내려가므로 소스를 열면 정답을 볼 수 있다. **수업용 정식 판정은 로컬 서버판(`npm start`)을 쓴다.**
- 로컬에서 빌드만 해 보기: `npm run build:pages` → `dist/` (커밋하지 않음)
- 빌드는 `public/` 전체(그림·소리·`assets/story.json`·지도 자료)와 `lib/*.mjs` 전체를 복사하고, HTML·CSS·JS의 경로를 모두 **상대 경로**로 만든다(저장소 하위 경로 `/저장소이름/`에서 동작). 루트 기준 `/assets/…` 경로가 남아 있으면 빌드가 실패한다. `/api/…` 요청은 `web-entry.mjs`가 브라우저 안에서 가로채며, `app.js`는 그 준비(`window.__htaApiReady`)를 기다린 뒤 시작한다.
- 체험판 화면은 `META.demo.badge/judgeNotice/storageNotice`를 그대로 보여 준다(“이 브라우저에서 확인”). 서버가 확인했다고 표시하지 않는다.

## 실행

Node.js 24 이상. 외부 의존성 없음(내장 `node:http`, `node:crypto`, `node:sqlite`만 사용).

```bash
node server.mjs          # 또는 npm start
# → http://127.0.0.1:3000
node --test "test/**/*.test.mjs"   # 또는 npm test
```

`node:sqlite`는 Node 24에서 실험 기능 경고를 출력할 수 있으나 동작에는 문제가 없다.

### 설정(환경 변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 바인딩 주소. 기본은 이 컴퓨터에서만 접속 가능 |
| `PORT` | `3000` | 포트 |
| `DATA_DIR` | `./data` | SQLite 저장 위치 (`.gitignore` 대상) |

API 키는 사용하지 않는다.

## 저장 방식

`data/game.sqlite` (SQLite, WAL). 서버를 재시작해도 아래가 복원된다.

- 플레이어(닉네임, 시대, 경험치, 식량(내부 필드명 grain), 인구), 세션 토큰의 **SHA-256 해시**(원문 토큰은 저장하지 않음)
- 플레이어별 지역 소유권·도전 진행, 카드, 시대 진입 기록
- 풀이 기록(attempts), 보상 기록(rewards, `(player, reward_key)` 기본키로 중복 차단: 문제 `q:<id>`·점령 `capture:<지역>`·미션 `m:<id>`)
- 문제 버전(question_versions: 문제 ID+버전별 원문 JSON), 진행 중인 1회용 도전(미션 문제면 `mission_id`)
- 제출 문제(검토 대기)

`data/`는 커밋하지 않는다.

**이전 저장 파일(v1) 이어 쓰기:** 서버(또는 체험판)가 열릴 때 `challenges`에 `mission_id` 열이 없으면 `ALTER TABLE`로 더하고(데이터 유지), 미션 보상이 없던 시절에 이미 조건을 채운 미션을 **한 번만** 정산한다. 지금 시대보다 뒤 시대의 미션은 정산하지 않는다. 여러 번 열어도 결과가 같다.

## 구현 범위

- 지도 중심 화면: 좌측 원정대 정보·시대 발전 진행률·미션, 가운데 SVG 지도(16개 지역, 확대/축소, 키보드 선택), 우측 지역 패널
- 9개 시대와 해제 조건(경험치·이전 시대 서로 다른 정답 6개·국력·필수 미션), 시대별 연대·요약, 자체 제작 문제 94개(구석기 10·신석기 10·청동기·고조선 13 + 삼국 이후 6개 시대 61), 모두 검수 대기
- 처음 3개 시대·16개 지역 id·카드 9장은 그대로 두었다. 삼국 이후 시대는 같은 지형을 쓰며 **시대별 정확한 국경을 그리지 않는다**(화면에 안내). 역사 지도 미리보기 탭은 지도 자료가 있는 3개 시대만 지원한다.
- 미션 45개(선사 시대 핵심 2~3개씩, 삼국 이후 시대마다 사건·기회 4~6개 + 핵심 1개). 미션마다 열린 까닭·목표·진행·정확한 보상(경험치·식량·인구, 일부 카드)을 미리 보여 주고, 보상은 서버가 한 번만 준다. 미션 문제(`POST /api/missions/:id/challenge`)는 그 미션에 정해 둔 문제에서만 나온다. 뒤 시대 미션은 잠겨 있다.
- 새 카드 6장(삼국 이후 시대마다 1장 이상, 미션 보상). 아직 삽화가 없어 코드로 그린 단순 상징 도형을 쓴다.
- 시작 화면 게임 방법 4단계, “게임 안내”·“배경 이야기” 다시 보기. 새 원정대는 배경 이야기(5장면) → 게임 안내 → 첫 미션 알림 순서로 보고, 돌아온 플레이어에게는 강제로 다시 보여 주지 않는다. 이야기 글은 `public/assets/story.json`을 그대로 쓴다.
- 시간여행 안내인(`public/journey.js`): 시대가 바뀌면 안내인 삽화의 복식과 장면 띠가 바뀐다. 복식은 학습용 상상 삽화이며 정확한 복원도가 아니고, 같은 인물이 실제로 수천 년을 살았다는 뜻도 아니다.
- 추리·탐구 노트(`public/inquiry.js`, `assets/inquiries.json`): 미리 준비한 단서 3개 사례 → 추론 선택 → 근거 쓰기. 피드백은 준비한 문장이며 **자유 문답 AI·서술형 자동 채점은 연결되지 않았다.** 경험치 보상이 없고, 쓴 글은 그 브라우저 localStorage에만 저장된다.
- 미션 추천(`public/recommendations.js`): 새 사건·기회 미션을 한꺼번에 쏟지 않고 그 시대 정답 2개마다 최대 1개씩(한 번에 2개까지) 알린다. 사건·기회 사이 순서는 단일 회차 표본 가중치(`lib/event-weights.mjs`)를 참고한다. 알림 순서만 정하며 미션 사용 가능 여부·보상은 서버(체험판은 브라우저 안 규칙 모듈)가 판정한다.
- 미션 알림은 대기열로 관리해 문제 풀이·이야기·시대 연출 창을 가리지 않고, 알린 미션은 플레이어별로 브라우저에 기억해 새로고침해도 다시 쏟아지지 않는다. 지도 아래 사건판(이번 시대 요약·미션 카드·시대 길잡이)과 위쪽 미션 단추로 언제든 다시 볼 수 있다.
- 닉네임 시작 → HttpOnly·SameSite=Strict 쿠키 세션
- 서버 전용 정답 판정, 1회용 도전 ID, 보기 순서 서버 셔플, 출제 응답에 정답·해설 없음
- 처음 정답 보상 / 반복 정답 무보상 / 오답 무손실 + 복습
- 중립 지역 정답 1회 점령, 시연용 경쟁 부족 지역 정답 2회 점령, 점령 보상 지역당 1회
- 카드 15장(유물·유적·기회·사건), 국력 계산식 공개
- 그림·소리: 배경·안내인·장면·유물 아틀라스는 이 게임용으로 만든 삽화(실제 유물 사진 아님). 배경음은 이 게임용으로 합성한 `assets/river-dawn.wav`(못 읽으면 WebAudio 즉석 소리), 효과음은 WebAudio. 배경음·효과음 모두 기본 꺼짐이고 사용자가 켠 뒤에만 재생하며 탭을 숨기면 멈춘다. `prefers-reduced-motion`이면 연출 애니메이션을 끈다.
- 문제 만들기: 형식 검사(보기 4개·중복·정답 번호·길이·출처 필수·욕설·전화번호/이메일/주민번호 패턴) 후 **검토 대기** 저장. **AI 검토 미연결.** 승인 기능이 없으므로 제출 문제는 출제·점령 보상에 쓰이지 않는다.
- 학습 기록·학습 노트(틀린 채 남은 문제는 정답을 숨김)·카드 도감·규칙 화면
- 보안: 정적 파일은 `public/`만 제공(경로 이탈 차단), CSP·nosniff·frame 차단, POST는 JSON만·16KB 제한·Origin 확인, 세션 생성 IP별 제한, 화면 출력은 `textContent`만 사용(XSS 방지)

초기 수치·규칙 상세는 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md) 참조.

## 문제 검수 상태

모든 문제는 자체 제작이며 **출처 원문을 직접 대조하지 않았으므로 "검수 대기"** 로 표시한다. 삼국 이후 문제에는 확인할 공식 기관 이름과 주소(우리역사넷·국가유산청·국립중앙박물관·국가기록원·독립기념관·대한민국역사박물관·5·18기념재단·민주화운동기념사업회·전쟁기념관·국립한글박물관·청주고인쇄박물관)를 붙였지만 역시 확인 완료가 아니다. 배경 이야기에 나오는 박정재 교수의 기후·이동 설명은 연구 가설로 구분해 보여 주며 **채점 문제로 내지 않는다.** 미션 배치에 쓰는 한국사능력검정시험(기본) 수치는 검토자가 분류한 **단일 회차 표본**(`lib/event-weights.mjs`)이며 공식 출제율이 아니다. 문제에 붙은 자료명(국립중앙박물관, 국사편찬위원회 우리역사넷, 국가유산청, 교육과정)은 "검수 때 확인할 곳"이며 확인 완료를 뜻하지 않는다. 신화(단군 건국 이야기) 관련 문제·카드는 "신화 해석/신화·설화"로 구분 표시한다. 기출문제 원문과 외부 이미지는 사용하지 않았다.

## 공개 서비스 전에 필요한 것 (미완료)

이 버전은 신뢰할 수 있는 로컬 환경 1인 시연용이다. 인터넷에 공개하기 전에 최소한 다음이 필요하다.

- HTTPS와 `Secure` 쿠키, 리버스 프록시 뒤 실제 클라이언트 IP 처리
- 교사/관리자 계정과 **서버 측 권한 검사**(현재 관리자 기능 없음), 학급 단위 접근 제어
- 전체 API 요청 빈도 제한, 계정·데이터 보존 기간과 삭제 기능, 보호자 동의 등 개인정보 정책
- 제출 문제의 사람 검토·승인 절차(작성자 확인 포함), 신고 기능
- 로그·백업·모니터링, 다중 프로세스 시 DB 동시성 검토

# 역사 영토 원정대 (로컬 1인 시연판 v0.1)

초등 5학년용 한국사 학습 지도 게임. 문제를 풀어 지역을 점령하고 구석기 → 신석기 → 청동기·고조선으로 시대를 발전시킨다.

> **이 버전은 로컬 1인 시연판이다.** 방 기반 온라인 경쟁, 참가 코드, 실시간 다중 사용자 동기화는 **구현되지 않았다.**
> 지도의 "경쟁 부족"은 시연용 컴퓨터 설정이며 실제 온라인 사용자가 아니다.
> 지도는 한반도를 닮게 독자 제작한 **시연용 지형**이며 실제 역사 국경이 아니다.

## 웹 1인 체험판 (GitHub Pages)

바로 해 보기: https://jjs760816-code.github.io/history-territory-adventure/

- 설치 없이 브라우저에서 실행된다. `main`에 올라오면 GitHub Actions(`.github/workflows/pages.yml`)가 `npm test` 통과 후 `node scripts/build-pages.mjs`로 `dist/`를 만들어 배포한다.
- 게임 규칙(`lib/game.mjs`)·콘텐츠·화면(`public/`)은 로컬 서버판과 같은 파일을 쓴다. 차이는 저장소와 판정 위치뿐이다.
  - 저장: `node:sqlite` 대신 sql.js(SQLite WASM, MIT, `pages/vendor/`에 포함)를 쓰고, DB를 **그 브라우저의 localStorage**에 보관한다. 다른 기기·브라우저와 공유되지 않는다.
  - 판정: 브라우저 안에서 한다. 문제은행이 함께 내려가므로 소스를 열면 정답을 볼 수 있다. **수업용 정식 판정은 로컬 서버판(`npm start`)을 쓴다.**
- 로컬에서 빌드만 해 보기: `npm run build:pages` → `dist/` (커밋하지 않음)

## 실행

Node.js 24 이상. 외부 의존성 없음(내장 `node:http`, `node:crypto`, `node:sqlite`만 사용).

```bash
node server.mjs          # 또는 npm start
# → http://127.0.0.1:3000
node --test "test/**/*.test.mjs"   # 또는 npm test
```

`node:sqlite`는 Node 24에서 실험 기능 경고를 출력할 수 있으나 동작에는 문제가 없다.

### 설정(환경 변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 바인딩 주소. 기본은 이 컴퓨터에서만 접속 가능 |
| `PORT` | `3000` | 포트 |
| `DATA_DIR` | `./data` | SQLite 저장 위치 (`.gitignore` 대상) |

API 키는 사용하지 않는다.

## 저장 방식

`data/game.sqlite` (SQLite, WAL). 서버를 재시작해도 아래가 복원된다.

- 플레이어(닉네임, 시대, 경험치, 식량(내부 필드명 grain), 인구), 세션 토큰의 **SHA-256 해시**(원문 토큰은 저장하지 않음)
- 플레이어별 지역 소유권·도전 진행, 카드, 시대 진입 기록
- 풀이 기록(attempts), 보상 기록(rewards, `(player, reward_key)` 기본키로 중복 차단)
- 문제 버전(question_versions: 문제 ID+버전별 원문 JSON), 진행 중인 1회용 도전
- 제출 문제(검토 대기)

`data/`는 커밋하지 않는다.

## 구현 범위

- 지도 중심 화면: 좌측 원정대 정보·시대 발전 진행률·미션, 가운데 SVG 지도(16개 지역, 확대/축소, 키보드 선택), 우측 지역 패널
- 3개 시대와 해제 조건, 자체 제작 문제 33개(구석기 10, 신석기 10, 청동기·고조선 13)
- 닉네임 시작 → HttpOnly·SameSite=Strict 쿠키 세션
- 서버 전용 정답 판정, 1회용 도전 ID, 보기 순서 서버 셔플, 출제 응답에 정답·해설 없음
- 처음 정답 보상 / 반복 정답 무보상 / 오답 무손실 + 복습
- 중립 지역 정답 1회 점령, 시연용 경쟁 부족 지역 정답 2회 점령, 점령 보상 지역당 1회
- 카드 9장(유물·유적·기회·사건), 미션 4개(필수 2개), 국력 계산식 공개
- 문제 만들기: 형식 검사(보기 4개·중복·정답 번호·길이·출처 필수·욕설·전화번호/이메일/주민번호 패턴) 후 **검토 대기** 저장. **AI 검토 미연결.** 승인 기능이 없으므로 제출 문제는 출제·점령 보상에 쓰이지 않는다.
- 학습 기록·학습 노트(틀린 채 남은 문제는 정답을 숨김)·카드 도감·규칙 화면
- 보안: 정적 파일은 `public/`만 제공(경로 이탈 차단), CSP·nosniff·frame 차단, POST는 JSON만·16KB 제한·Origin 확인, 세션 생성 IP별 제한, 화면 출력은 `textContent`만 사용(XSS 방지)

초기 수치·규칙 상세는 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md) 참조.

## 문제 검수 상태

모든 문제는 자체 제작이며 **출처 원문을 직접 대조하지 않았으므로 "검수 대기"** 로 표시한다. 문제에 붙은 자료명(국립중앙박물관, 국사편찬위원회 우리역사넷, 국가유산청, 교육과정)은 "검수 때 확인할 곳"이며 확인 완료를 뜻하지 않는다. 신화(단군 건국 이야기) 관련 문제·카드는 "신화 해석/신화·설화"로 구분 표시한다. 기출문제 원문과 외부 이미지는 사용하지 않았다.

## 공개 서비스 전에 필요한 것 (미완료)

이 버전은 신뢰할 수 있는 로컬 환경 1인 시연용이다. 인터넷에 공개하기 전에 최소한 다음이 필요하다.

- HTTPS와 `Secure` 쿠키, 리버스 프록시 뒤 실제 클라이언트 IP 처리
- 교사/관리자 계정과 **서버 측 권한 검사**(현재 관리자 기능 없음), 학급 단위 접근 제어
- 전체 API 요청 빈도 제한, 계정·데이터 보존 기간과 삭제 기능, 보호자 동의 등 개인정보 정책
- 제출 문제의 사람 검토·승인 절차(작성자 확인 포함), 신고 기능
- 로그·백업·모니터링, 다중 프로세스 시 DB 동시성 검토
